# Desafio-DIO-_Prompts_para_automacao

Atue como um especialista em N8N.

Crie uma automação para encontrar bons artigos de pesquisa científica.

## Público:
Pesquisadores científicos.

## Ferramentas envolvidas:
[Google Academy](https://scholar.google.com/?hl=pt-BR),
[Gmail](https://mail.google.com/mail/u/0/),
[Google Sheets](https://docs.google.com/spreadsheets/create).

## Fluxo:
**1**- Fazer uma pesquisa por filtro de palavras;
**2**- Enviar email dos artigos coletados para a etapa de verificação;
**3**- Se aprovada a fonte é incorporada a uma planilha. 

## Regras:
Adicione um prazo de até o próximo sábado para a validação da pesquisa antes de fazer uma próxima. 

Explique quais nós do N8N devem ser utilizados e a lógica de funcionamento do workflow.
